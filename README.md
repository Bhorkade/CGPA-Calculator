# CodeAlpha Login & Registration System

A C++ console-based Login and Registration System developed as part of the CodeAlpha C++ Programming Internship.

## 📌 Project Overview

This application provides a simple registration and login system. Users can register with a username and password, while existing users can authenticate using their credentials.

## ✨ Features

* User registration
* Username validation
* Duplicate username detection
* Password validation
* File-based credential storage
* User login
* Authentication
* Success and error messages

## 🛠️ Technologies Used

* C++
* File Handling
* Functions
* Conditional Statements
* Loops
* String Handling

## 📂 Project Structure

```text
CodeAlpha_LoginRegistration/
│
├── main.cpp
├── users.txt
└── README.md
```

`users.txt` is generated by the application when a user registers.

## ▶️ How to Run

Compile:

```bash
g++ main.cpp -o login
```

Run:

```bash
./login
```

On Windows:

```bash
login.exe
```

## ⚠️ Security Note

This project is designed as an educational internship project. Production authentication systems should use secure password hashing and should never store plaintext passwords.
